Task Manager – A Web-Based To-Do List Application
 Project Overview
Task Manager is a simple and user-friendly web application designed to help users organize their daily activities and manage tasks efficiently. It allows users to create, view, update, and delete tasks while keeping track of their work and improving productivity.

 Features
Add Tasks: Create new tasks with ease.
View Tasks: Display all added tasks in an organized list.
Update Tasks: Edit existing task details.
Delete Tasks:Remove completed or unnecessary tasks.
Task Tracking: Manage daily activities efficiently.
User-Friendly Interface: Simple and responsive design.

Objective
The main objective of this project is to provide an easy-to-use platform for managing daily tasks, improving time management, and increasing productivity.
 Purpose
This project is developed to demonstrate web development skills and practical implementation of CRUD (Create, Read, Update, Delete) operations.
